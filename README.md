## Start here

1. Add the existing Google Sheet link above and in `01-literature-review/README.md`.
2. Give teammates Google Sheet Editor access separately from GitHub access.
3. Invite each teammate through repository Settings → Collaborators. Members may be added later.
4. Assign review papers and initial tasks; keep the shared sheet as the live review record.
5. Replace TODOs with verified work. Do not present templates as completed submissions.
6. Read [collaboration instructions](11-team-workspace/collaboration-guide.md).

Empty folders contain `.gitkeep` so Git preserves them. Delete that file when real content is added if desired. No paper PDFs, existing spreadsheet, datasets or results have been included in this starter.

## Reproducibility and attribution

Record baseline repository URL, commit, license, environment, data splits and seeds before experiments. Preserve upstream notices when reusing code. Store large datasets/checkpoints externally and document access. Choose a license with the team and supervisor before releasing reusable code.
